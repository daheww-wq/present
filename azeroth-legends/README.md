# ⚔️ 아제로스 레전드 (Azeroth Legends)

WoW에서 영감을 받은 **브라우저 RPG**입니다. 설치나 빌드 없이 `index.html`을 열면 바로 플레이할 수 있습니다.

## 플레이 방법

```bash
# 그냥 index.html을 브라우저로 열거나
python3 -m http.server 8080   # 후 http://localhost:8080
```

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 자유 이동 (실시간) |
| Space | 기본 공격 (근접 직업은 휘두르기, 원거리 직업은 자동 조준 투사체) |
| 1 ~ 6 | 직업 기술 (쿨다운은 액션 바에 표시) |
| Q | 치유 물약 |
| E | 근처 NPC와 대화 (📜 퀘스트, 🧑‍🌾 상인, 🍺 여관) |
| C / I / L / K / N | 캐릭터 / 가방 / 퀘스트 / 기술 / 특성 탭 |

모바일에서는 화면의 방향 패드와 ⚔️ 버튼, 액션 바를 터치하면 됩니다.

## 콘텐츠

| 시스템 | 내용 |
|---|---|
| 캐릭터 외형 | 캔버스로 직접 그리는 픽셀 캐릭터. 종족별 피부·머리, 직업별 무기, **착용한 장비(투구·갑옷·다리·신발·무기·장신구)가 그대로 표시** |
| 종족 6 | 인간, 드워프, 나이트 엘프 (얼라이언스) / 오크, 언데드, 트롤 (호드) |
| 직업 6 | 전사(분노), 마법사·사제·사냥꾼·성기사(마나), 도적(기력) — 직업별 기술 6종 |
| 실시간 전투 | 몬스터가 쫓아오고 예고 후 공격. 치명타·화면 흔들림·데미지 숫자·보호막·지속 피해·기절·약화 |
| 지역 5 | 새벽숲 → 잿빛 황야 → 어둠골 습지 → 서리봉 산맥 → 불타는 심연 (Lv 1~30) |
| 우두머리 5 | 은신처에서 기다리는 우두머리를 처치해야 다음 지역 포탈이 열립니다 |
| 퀘스트 15 | 처치 / 수집 / 우두머리 연계 퀘스트 |
| 전리품 | 바닥에 떨어진 골드·장비·물약을 밟아서 획득. 일반/고급/희귀/영웅 등급 |
| 특성 | 레벨 10부터 3개 전문화 트리에 포인트 투자 |
| 저장 | 30초마다 자동 저장 + 여관 휴식 시 저장 (localStorage) |

## 구조

```
azeroth-legends/
├── index.html      # 화면 구조
├── style.css       # 스타일
└── js/
    ├── data.js     # 종족·직업·기술·지역·몬스터·퀘스트·아이템 데이터
    ├── sprite.js   # 장비가 반영되는 캐릭터 스프라이트 렌더러
    └── game.js     # 엔진: 월드 생성, 실시간 이동·전투, 퀘스트, 인벤토리, 특성, 저장
```

`js/data.js`만 수정해도 새 지역·몬스터·퀘스트·직업을 추가할 수 있습니다.
